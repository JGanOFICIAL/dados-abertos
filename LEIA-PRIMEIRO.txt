ACADEMIA UNIÃO FITNESS — PACOTE ATUALIZADO

Página pública única: index.html
Painel administrativo: admin.html
Arquivos de estilo e lógica: style.css, admin.css, app.js, admin.js e script.js.

Atualizações:
- Removido o fluxo de conta/login e as páginas Minha Conta e Consultas separadas.
- Inscrição e consulta na mesma página, usando CPF.
- CPF validado e usado para localizar inscrições anteriores e oferecer preenchimento dos dados.
- Foto solicitada como campo opcional.
- Pagamento com valor, chave Pix, instruções claras e botão para WhatsApp quando configurado.
- Consulta lista as inscrições encontradas pelo CPF e permite abrir o documento/status.
- Lista administrativa exportável em CSV e PDF com nome completo, CPF e número de inscrição.
- Numeração calculada com base nas inscrições existentes: se não houver inscrições, recomeça em 0001; se houver números posteriores, continua após o maior número existente.
- Rodapé branco, VLibras removido, cabeçalho preto por padrão e cor configurável no administrativo.

CONFIGURAÇÃO
1. Publique os arquivos juntos em hospedagem HTTPS, como GitHub Pages.
2. Configure o Firebase Realtime Database e as regras de acesso.
3. O preset Cloudinary deve permitir upload unsigned para imagens.
4. Configure chave Pix, valor e WhatsApp no painel administrativo.

IMPORTANTE
Esta versão usa Firebase diretamente do navegador, como o projeto original. Antes de usar dados reais, configure regras seguras no Realtime Database. Uma consulta por CPF não deve ser considerada autenticação forte: regras abertas podem expor dados pessoais. A lógica no navegador não consegue garantir segurança contra manipulação de dados sem regras adequadas no banco.
